# Security Policy

## Supported Versions

Only the latest release of Analog Gothic receives security fixes. See [Releases](https://github.com/hastefuI/analog-gothic/releases) for the current version.

## Reporting a Vulnerability

See [GitHub's private vulnerability reporting](https://github.com/hastefuI/analog-gothic/security) feature for this repository to report a vulnerability.

Provide as much detail as possible to help reproduce the issue and assess impact.
